# Working rules for the Stick Souls project (`stick-souls/`)

1. Don't agree with the user blindly. Be critical of every suggestion or idea they bring, and give your own point of view with the reasons.
2. Don't assume. Ask when there are gaps, or when a task would need major changes that the request didn't mention.
3. The souls games are the default: base suggestions and answers on them (this project only).
4. Every suggestion, idea or change applied to the game must take into account that the game is 2D, not 3D.
5. Only suggest replacing a souls mechanic with a 2D-specific one when keeping the souls version would critically change or break the game in 2D. When you do, give your point of view with the reasons.
